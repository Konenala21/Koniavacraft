# Product Guide: Koniavacraft

## # Initial Concept
結合魔法幻想與工業自動化的 NeoForge 模組，強調「台灣工廠風格」的流程感與穩定性，並引入 RPG 角色成長要素來驅動工業效率。

## Vision
打造一個獨特的 Minecraft 模組，將高奇幻魔法與紮實的工業自動化完美融合。呈現出獨特的「台灣工廠」美學——務實、流程清晰、強調良率與穩定的「製程」體驗，並透過 Nara System 引導玩家深入世界觀。

## Target Audience (多重面向)
*   **科技模組愛好者:** 喜歡設計產線、優化效率、計算能耗比的玩家。
*   **RPG 玩家:** 希望角色成長能回饋到工業產能，將冒險與建設連結的玩家。
*   **風格追求者:** 喜愛魔法陣、光束特效等獨特視覺風格，以及敘事引導體驗的玩家。

## Core Value Proposition
*   **穩定的自動化:** 強調確定性的生產流程，減少 RNG，體驗「接單生產」的快感。
*   **RPG 連動:** 玩家屬性直接提升機器運作效率，角色培育是工業擴張的關鍵。
*   **沉浸式引導:** 透過 Nara System 提供獨特的敘事與引導體驗，非單純的工具書。

## Key Features
### 核心工業與魔法
*   **魔法工業機器群:** 魔力發電機、注入機、粉碎機等，結合 IO 配置與升級系統。
*   **奧術導管網路:** 虛擬網路運算的高效傳輸系統，解決 TPS 延遲。
*   **台灣工業流:** 「粉碎 → 注入 → 精煉 → 成品」的清晰加工邏輯。
*   **視覺特效 (VFX):** 內建 Magic Circle (魔法陣)、Beam (光束) 等粒子特效系統，強化魔法氛圍。

### 獨特系統
*   **Nara System:** 包含銘印 (Imprint) 與對話系統，作為核心敘事與引導框架。
    *   **引導體驗 (Intro Sequence):** 透過打字機特效與音效，提供沈浸式的開場引導。
    *   **銘印機制 (Imprint):** 玩家與世界的深層綁定，將作為後續解鎖高階內容的鑰匙。
*   **生物群系整合:** 自定義生態系統 (Ecosystem) 與地形生成。

### 技術架構
*   **Auto-Sync:** 自研反射同步框架。
*   **ModularScreen:** 高度模組化的 Widget GUI 系統。
*   **FlexLayout:** 彈性佈局系統，支援複雜的介面排版。

## Non-Functional Requirements
*   **性能優化:** 針對大量機器與特效渲染進行優化。
*   **本地化:** 支援繁體中文 (zh_tw) 與英文 (en_us)。
