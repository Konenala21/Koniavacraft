?# Koniavacraft - 魔法工業模組

**語言**: 繁體中文 | [English](./README_EN.md)

> 魔法不只是特效，它是動力來源。  
> 這個模組把幻想世界的能量系統做成你可以真正操作的機器。

---

## 這個模組在幹嘛

核心概念是「魔力工業」——用魔力驅動機器、傳輸能量、建造自動化系統。

目前有的東西：
- 魔力發電機（Mana Generator）
- 弧光導管（Arcane Conduit）能量傳輸網路
- 自訂生態域與地形生成
- 更多內容持續開發中

這不是一個大而全的 kitchen-sink 模組，是我自己的創作實驗。有些功能存在只是因為我覺得有趣。

## 想一起開發？

歡迎，但先說清楚幾件事：

**環境需求**
- NeoForge 1.21.1
- Java 21
- 建議先玩過模組再來改，比較不會問奇怪的問題

**流程**
- Fork 之後開 feature 分支
- PR 之前自己跑一遍編譯跟遊戲測試，別讓我幫你踩地雷
- 歡迎 Bug 回報跟功能討論
