# Koniavacraft - Magical Industrial Mod

**Language**: [繁體中文](./README.md) | English

> Magic isn't just visual effects — it's a power source.  
> This mod turns fantasy energy systems into machines you can actually build and operate.

---

## What This Mod Does

The core idea is "mana-industrial" — using magical energy to power machines, transmit mana, and build automation systems.

What's currently in:
- Mana Generator
- Arcane Conduit energy transport network
- Custom biomes and terrain generation
- More stuff in progress

This isn't a kitchen-sink mod trying to do everything. It's my personal creative project, and some features exist purely because I thought they'd be interesting.

## Want to Contribute?

You're welcome, but a few things upfront:

**Requirements**
- NeoForge 1.21.1 dev environment
- Java 21
- Recommended: actually play the mod before diving into the code. You'll have fewer weird questions.

**Process**
- Fork and create a feature branch
- Run a full compile + in-game test before submitting a PR — don't push untested code
- Bug reports and feature discussions are welcome

---

## Suggestions?

Open an Issue, but keep these in mind:

- This is my personal creative work, not a commission. I'll implement what I want to implement.
- No update schedule. It updates when it updates.
- Design feedback is fine. "You should do X" as a demand isn't.
